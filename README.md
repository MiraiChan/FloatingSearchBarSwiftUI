
# FloatingSearchDemo — SwiftUI

The new floating search experience in iOS 26, focusing on search placement, toolbar integration, and tab-based navigation.

## Overview

Demonstrates how SwiftUI adapts search presentation based on the navigation structure:

- **NavigationStack** — Floating search field using `.searchable`.
- **Bottom Toolbar** — Search integration with `DefaultToolbarItem` and `.searchToolbarBehavior(.minimize)`.
- **TabView** — Dedicated search tab using `Tab(role: .search)` and `.tabViewSearchActivation(.searchTabSelection)`.

## Key Highlights

- Native iOS 26 floating search behavior
- Integration with SwiftUI navigation and toolbars
- Declarative search UI using modern SwiftUI APIs
